# PlacementHub

PlacementHub is a full-stack MERN placement-management application.

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT authentication
- bcrypt
- Git/GitHub

## Codex Rules
- Inspect existing code before making changes.
- Keep frontend and backend separated.
- Use MongoDB for this project. Do not switch to SQL.
- Never hard-code passwords, API keys, database credentials, or JWT secrets.
- Never commit `.env` files.
- Use proper authentication and role-based authorization.
- Prefer small, focused changes instead of rewriting unrelated code.
- Reuse existing components and logic where appropriate.
- Run relevant tests/build/lint checks after changes.
- For UI changes, verify the result in the browser when possible.
- Check `git status` before substantial changes.
- Do not commit or push unless explicitly asked.
- Do not overwrite unrelated uncommitted work.
- Explain what changed after completing a task.

## Main Roles
- Student
- Recruiter / Company
